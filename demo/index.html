    How to read this demo

    This research asks: is an LLM's refusal of a harmful request anchored to the script it's written in, or to its meaning? We rewrite harmful prompts into romanized / obfuscated scripts (Arabic→Arabizi, Devanagari→ITRANS, English→Leetspeak) and measure refusal behaviourally, geometrically (refusal direction), representationally (SAE features), and causally (activation patching) across ten open models.

    Use the tabs above to interact: switch a prompt's script in the Playground, explore the comprehension gate that separates a real bypass from "the model didn't understand", compare every model in the heatmap, and inspect the H6 patching curves.

    Every number is generated from results/ by demo/build_data.py — nothing is hand-typed in the page.

    The Meaning Is Recoverable, and the Model Does Not Act on It

    Two measurements of whether a model recovers the meaning of a rewritten request. Neither lets the model produce a response, so a refusal cannot enter the measure. Both are compared against engagement, the share of the same 50 requests the model answered or refused.

    Transliteration, with no judge in the loop

    The model is asked to rewrite each ITRANS request in Devanagari. The output is scored against the known correct text by character similarity, so nothing here depends on an LLM judge.

    On topic is not harmful

    The engagement judge is told to ignore whether content is harmful, so its on-topic label marks a warning about explosives and a recipe for one alike. Every on-topic harmful response was judged a second time, by a different model family, for whether it contains specific usable harmful content.

    Decode, then refuse

    A fix that needs no retraining. The model is asked to rewrite the request in its native script, then answer its own rewriting. The native-script arm is the ceiling the method is trying to reach.

    Script Switcher Playground

    Take a real (benign, safe) prompt from the corpus and flip its script. The meaning is identical — only the orthography changes. Then see how each model actually behaves on the matched harmful set for that script pair. The question: when refusal drops on the romanized side, is it anchoring — or did the model just fail to read it?

    H1 — Behavioural asymmetry

    Does refusal collapse when a harmful prompt is romanized? Native scripts (Arabic / English / Devanagari) refuse; their romanized twins (Arabizi / Leetspeak / ITRANS) do not. But switch the metric to off-topic: most romanized "non-refusal" is the model producing unrelated text — a reading failure, not a clean bypass (that distinction is H4).

    H3 — Orthographic feature overlap

    Do SAE features for a harmful prompt fragment when only the script changes? We compare top-100 SAE feature overlap (Jaccard) for: a within-script paraphrase (should stay HIGH — tracks meaning), a language change, the script change (the headline — should be LOW), and a benign script change. The catch: if benign is also low, fragmentation is generic surface, not harm-specific.

    Headline script overlap across all models (Tier A: Arabic↔Arabizi, 99% CI)

    Point + 99% bootstrap CI. A model "supports" orthographic fragmentation when its CI lies below 0.4. Transcoder models (Qwen3) are an MLP-feature analogue, not directly comparable to the residual-SAE models.

    H4 — The Comprehension Gate

    The core idea of the paper. X = how well the model comprehends the distorted script (clean LLM judge, §4.1). Y = SAE feature overlap when only the script changes (lower = features fragment = candidate anchoring). A low overlap is only interpretable if the model actually understood the text — otherwise it's "garbage in". Only points in the shaded zone (high comprehension + low overlap) can speak to anchoring.

    Refusal Returns Wherever Comprehension Does

    The decisive within-model test (paper Table 2). Conditioning refusal on judged comprehension, item by item: within the comprehended subset, does the model still refuse? If safety is intact and merely only short of input, refusal on the requests it does read should return to native levels. It does not: recovering the meaning roughly doubles the chance of a refusal and still leaves most of those requests unrefused.

    The positive half — direction transfer

    Refusal correlating with comprehension is not the same as the same native refusal direction mediating it. On the comprehended-Arabizi subset (read & refused), we ablate the native (Arabic) direction vs. a norm-matched random control: if the native direction removes refusal and random does not, the native mechanism is the one producing those refusals. This holds in the three Gemma Arabizi cells and fails in the one well-powered cell outside that family.

    H5 — Geometry & the Wang silhouette gap

    Wang (2025) reported an Arabic-vs-English silhouette of 0.24 read as orthographic interference. We test whether it reproduces. Silhouette = how cleanly harmful/benign separate along the per-script refusal direction; cosine = how aligned two scripts' directions are (low = near-orthogonal).

    H2 — Is the refusal direction script-specific?

    We extract a refusal direction per script and ablate it. The registered headline index forward − reverse flip is confounded by baseline saturation: when a romanized variant already barely refuses, there is almost nothing left to "flip", so the index reads ≈0pp even when the direction is highly specific. The confound-free metric is the same-target contrast: on one fixed target, does the native-script direction control refusal while the variant-script direction does not?

    The confound, across all models

    Blue = same-target contrast (real signal). Red tick = forward−reverse (the registered index) — note how it collapses to ≈0 everywhere despite a large real effect.

    H6 — Activation Patching

    If refusal were script-anchored, patching the native-script residual into the romanized run should specifically restore refusal — more than a random unrelated harmful residual would. It does not. The matched and random curves track each other; self and benign stay near zero. The position carries a transferable decision/harm-state, not a script anchor.
